About XHTML

XHTML stands for Extensible HyperText Markup Language. It is a stricter version of HTML that follows XML rules. XHTML documents are well-structured and easy for browsers to understand.

Features of XHTML

  • All tags are written in lowercase.
  • Every tag is properly closed.
  • Attribute values are enclosed in quotes.
  • Elements are properly nested.
  • Empty tags are self-closing.
